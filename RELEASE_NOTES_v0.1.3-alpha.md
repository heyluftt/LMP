# LMP v0.1.3 Alpha

Patch alpha after v0.1.2-alpha.

## Changes

- First alpha with in-app updater support.
- Adds updater UI in Settings.
- Adds signed updater artifacts and latest.json manifest flow.
- Improves cache controls and cache visibility.
- Adds media inspection probe cache.
- Polishes settings/update UI and timeline focus styling.

## Known Limitations

- Still an unsigned alpha build.
- Native playback depends on Windows/WebView codec support.
- Terminal execution uses saved files, not unsaved drafts.
- Shell scripts require bash in PATH.
- DOC/DOCX handling extracts editable text copies; it is not full Word editing.

## Update Note

v0.1.3 is the first updater-capable build. In-app updates can be tested with a later release such as v0.1.4.
